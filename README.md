# نظام إدارة ورشة خبراء هونداي وفورد (workshop_smart_app)

نظام برمجي متكامل لإدارة ورش صيانة السيارات، تتبع العملاء، المركبات، إصدار الفواتير، وحساب تكاليف قطع الغيار وأجور اليد بالريال.

## 📍 بيانات الورشة الأساسية
* **اسم الورشة:** ورشة خبراء هونداي وفورد
* **رقم التواصل:** 775008077
* **العنوان:** صنعاء، جولة ٤٥، خلف مطعم الخطيب

## 📂 هيكلية ملفات المشروع
* `config.json`: ملف التكوين والإعدادات الأساسية للورشة.
* `database.py`: إنشاء وتهيئة قاعدة البيانات (SQLite) وجداول العملاء والفواتير.
* `app.py`: الدوال البرمجية الأساسية لإضافة العملاء وإصدار الفواتير.
* `reports.py`: استعراض تقارير العملاء، سياراتهم، والفواتير المسجلة وإجمالي الإيرادات.
* `cli.py`: القائمة التفاعلية الرئيسية لتشغيل وإدارة النظام بسهولة.
