# نظام إدارة ورشة خبراء هونداي وفورد

تطبيق لإدارة العملاء والمركبات، تقارير فحص الكمبيوتر وأكواد الأعطال DTC، فواتير الصيانة، ومخزون قطع الغيار.

## تطبيق Android

أُضيف تطبيق Android أصلي بواجهة عربية، ويخزن البيانات محليًا في قاعدة SQLite خاصة بالتطبيق على الهاتف. يشمل تسجيل العملاء والمركبات، تسجيل تقارير الفحص، إصدار الفواتير وعرض إجمالي الإيرادات، وإضافة/تحديث المخزون.

### البناء والتشغيل محليًا

- افتح المستودع في Android Studio حديث يدعم Android Gradle Plugin 8.7.3.
- استخدم JDK 17، ثم نفّذ مزامنة Gradle.
- شغّل مهمة `app > Tasks > build > assembleDebug` أو من الطرفية:

```bash
gradle assembleDebug
